Illustrious Danbooru Prompt Tool

Illustrious系画像生成向けの、Danbooruタグ・プロンプト整理ツールです。

過去に作ったプロンプトやタグ列を貼り付けて、用途別セクションに整理し、編集・再利用しながら最終プロンプトを作成できます。

公開ページ

https://ohno-nori.github.io/illustrious-danbooru-prompt-tool/

主な機能

・タグ貼り付け整理
・セクション別プロンプト編集
・最終プロンプトとネガティブプロンプトの出力
・CSV / JSON / テキスト辞書の読み込み
・検索式タグ辞書
・辞書の階層フィルター
・general / NSFW 分類
・お気に入りタグ
・最近使ったタグ
・プロンプトメモ
・JSONインポート / エクスポート
・localStorage保存
・PWA対応

基本的な使い方
過去プロンプトやタグ列を「タグ貼り付け整理」に貼り付ける
タグ整理を実行する
整理結果を各セクションに反映する
必要に応じて各セクションを編集する
最終プロンプトをコピーして画像生成ツールで使う

辞書CSVを読み込むと、タグ検索・お気に入り登録・最近使ったタグ・貼り付け整理時の分類補助に使えます。

辞書CSV形式

推奨CSV形式は以下です。

ジャンル,サブジャンル1,サブジャンル2,ラベル,プロンプト,分類

各列の役割は以下のとおりです。

・ジャンル：階層フィルター用
・サブジャンル1：階層フィルター用
・サブジャンル2：階層フィルター用
・ラベル：日本語表示名
・プロンプト：Danbooruタグ、またはカンマ区切りの複数タグ
・分類：general または nsfw

データ保存について

このツールはブラウザ内で動作します。

入力したプロンプト、辞書、メモなどのデータは、基本的に使用中のブラウザの localStorage に保存されます。
サーバー側データベースはありません。

そのため、以下の場合は保存内容が消えることがあります。

・ブラウザデータを削除した場合
・別のブラウザで開いた場合
・別の端末で開いた場合
・シークレットモードやプライベートブラウズで使用した場合
・ブラウザやOSの設定によりlocalStorageが削除された場合

重要な辞書やプロンプトメモは、JSONエクスポートでバックアップしてください。
