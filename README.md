Illustrious Danbooru Prompt Tool

Illustrious系画像生成向けの、Danbooruタグ・プロンプト整理ツールです。

過去に作ったプロンプトやタグ列を貼り付けて、用途別セクションに整理し、編集・再利用しながら最終プロンプトを作成できます。

ブラウザだけで動作し、入力内容をサーバーへ送信する設計ではありません。

公開ページ

https://ohno-nori.github.io/illustrious-danbooru-prompt-tool/

主な機能

・タグ貼り付け整理
・セクション別プロンプト編集
・最終プロンプトとネガティブプロンプトの出力
・検索式タグ辞書
・辞書CSVの読み込み
・辞書の階層フィルター
・general / NSFW 分類
・お気に入りタグ
・最近使ったタグ
・プロンプトメモ
・バックアップJSONエクスポート / インポート
・localStorage保存
・PWA対応

基本的な使い方
過去プロンプトやタグ列を「タグ貼り付け整理」に貼り付ける
タグ整理を実行する
整理結果を各セクションに反映する
必要に応じて各セクションを編集する
最終プロンプトをコピーして画像生成ツールで使う

辞書CSVを読み込むと、タグ検索・お気に入り登録・最近使ったタグ・貼り付け整理時の分類補助に使えます。

辞書を育てるほど、過去プロンプトやタグ列を整理するときの分類精度を上げやすくなります。

プロンプト編集セクション

現在のプロンプト編集欄は、以下のセクションに分かれています。

・スタイル
・構図・動作
・主体
・外見
・衣装
・背景・ライティング
・その他
・ネガティブプロンプト

ネガティブプロンプトは、最終プロンプトとは別に出力されます。

辞書CSV形式

辞書CSVは以下の形式に対応しています。

ジャンル,サブジャンル1,サブジャンル2,ラベル,プロンプト,分類

各列の役割は以下のとおりです。

・ジャンル：階層フィルター用
・サブジャンル1：階層フィルター用
・サブジャンル2：階層フィルター用
・ラベル：日本語表示名
・プロンプト：Danbooruタグ、またはカンマ区切りの複数タグ
・分類：general または nsfw

例：

ジャンル,サブジャンル1,サブジャンル2,ラベル,プロンプト,分類
背景,水辺・海,,海,ocean,general
表情,笑顔,,笑顔,smile,general
構図,距離感,上半身,上半身,upper body,general

辞書について

このリポジトリには、個人用辞書やNSFW辞書は同梱していません。

辞書CSVは、ユーザーが必要に応じて自分で読み込んで使用する想定です。

辞書は完成プロンプト集ではなく、タグを探す・分類する・再利用するためのタグ単語帳として扱います。

データ保存について

このツールはブラウザ内で動作します。

入力したプロンプト、辞書、お気に入りタグ、最近使ったタグ、プロンプトメモなどのデータは、基本的に使用中のブラウザの localStorage に保存されます。

サーバー側データベースはありません。
入力内容をサーバーへ送信する設計ではありません。

そのため、以下の場合は保存内容が消えることがあります。

・ブラウザデータを削除した場合
・別のブラウザで開いた場合
・別の端末で開いた場合
・シークレットモードやプライベートブラウズで使用した場合
・ブラウザやOSの設定によりlocalStorageが削除された場合

重要な辞書やプロンプトメモは、バックアップJSONエクスポートで保存してください。

PWAについて

このツールはPWA対応を想定しています。

スマホやPCのブラウザからホーム画面に追加することで、アプリのように使える場合があります。

ただし、PWAとしての動作やホーム画面追加の可否は、使用する端末・OS・ブラウザによって異なります。
